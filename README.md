# 🫧 Bubble Pop - Bubble Shooter Game

A fun, responsive bubble shooter game that works on mobile, tablet, and desktop.

## How to Play
- **Desktop**: Move mouse to aim, click to shoot
- **Mobile/Tablet**: Tap to aim and shoot
- Match **3 or more** same-colored bubbles to pop them
- Floating (disconnected) bubbles fall for bonus points
- Chain combos for score multipliers
- Clear all bubbles to advance to the next level

## Features
- 6 vibrant bubble colors with glossy 3D rendering
- Particle explosion effects
- Combo system with multiplied scores
- Progressive difficulty across levels
- Fully responsive — works on any screen size
- Zero dependencies — single HTML file
